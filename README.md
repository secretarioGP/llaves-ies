# 🔑 Llaves IES Gregorio Prieto

App PWA para consultar y gestionar el cajetín de llaves del IES Gregorio Prieto (Valdepeñas).

## Cómo publicarla en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `llaves-ies`) y márcalo como **Public**.
2. Sube **todos** los archivos de esta carpeta a la raíz del repositorio.
3. En el repositorio: **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / carpeta `/ (root)`
   - **Save**
4. Espera 1-2 minutos. La URL será:
   `https://TU-USUARIO.github.io/llaves-ies/`

## Instalar como app en el móvil

- **Android (Chrome):** abre la URL → menú ⋮ → *Instalar aplicación*
- **iPhone (Safari):** abre la URL → botón compartir → *Añadir a pantalla de inicio*
